What Is a Boolean Algebra?

Definition

A Boolean algebra is a set B together with:

  • two binary operations + (Boolean sum, OR) and · (Boolean product, AND)
  • one unary operation ′ (complement, NOT)
  • two distinct elements 0 and 1

such that the commutative, distributive, identity and complement laws hold for every x, y, z in B (Huntington’s postulates).

Order of operations
( )→′→·→+

Example: x + y.z' means x + (y.(z'))

The two-element Boolean algebra B = {0, 1}

The Laws of Boolean Algebra

1 + 1 = 1

Weird but true. TRUE OR TRUE is still just TRUE. This is not ordinary arithmetic.

x + yz = (x + y)(x + z)

Spot the surprise. This law fails for numbers: 2 + 3·4 = 14, but (2 + 3)(2 + 4) = 30.

The Principle of Duality

The dual of an expression swaps + ↔ · and 0 ↔ 1, leaving variables and complements alone. If an identity is true, its dual is true too: prove one law and you get its partner free.

Switching Circuits

In 1938 Claude Shannon showed that circuits of switches follow exactly the laws of Boolean algebra.

SERIES = ANDPARALLEL = ORLAMP = OUTPUT

A Switch Is a Boolean Variable

Switch x
Switch x′
Same label, same state. All switches marked x open and close together, as if linked by one lever.
x′ is always opposite. Click either switch: when x closes, x′ opens.
The lamp is the output. Lamp ON = 1, lamp OFF = 0, so a circuit computes a Boolean function.

Series = AND, Parallel = OR

SeriesF = x · y

Current must pass through both switches, so the lamp is ON only when x AND y are closed.

ParallelF = x + y

Current can take either path, so the lamp is ON when x OR y (or both) is closed.

Q1

The Six-Switch Puzzle

Question 1

Three pairs of parallel switches are wired in series with a lamp: (x ∥ y), (x ∥ y') and (x' ∥ z). Find the Boolean function and design the simplest equivalent circuit.

Solution
  1. 1
    F = (x + y)(x + y')(x' + z)
    Parallel = sum, series = product
  2. 2
    (x + y)(x + y')= x + [[yy']]= x + 0= x
    Distributive, complement and identity laws
  3. 3
    F = x(x' + z)= [[xx']] + xz= 0 + xz
    Distributive and complement laws
  4. 4
    F = xz
    Identity law
Answer: F = xz

Only x and z in series: 6 switches → 2.

Toggle x, y, z: both lamps always agree

Q2

The Redundant Branch

Question 2

A lamp is controlled by three parallel branches: x–y, x'–z and y–z. An electrician says the red branch wastes two switches. Prove it.

Try it: close y and z, then flip x. Another branch is always carrying current too.

Solution
  1. 1
    F = xy + x'z + yz
    Read the circuit
  2. 2
    yz = yz(x + x')= xyz + x'yz
    Identity and complement: x + x′ = 1
  3. 3
    F = xy(1 + z) + x'z(1 + y)
    Regroup with the distributive law
  4. 4
    F = xy + x'z✓
    Domination (1 + z = 1) and identity
Consensus theorem: xy + x'z + yz = xy + x'z

The red branch is never needed. 6 switches → 4.

Both lamps always agree

Q3

The Hostel AC Vote

Question 3

Roommates A, B and C each have a switch. The room AC turns ON only when at least two of them vote YES. Find the simplest switching circuit.

Solution
  1. 1
    F = Σm(3, 5, 6, 7)
    Columns of the truth table where F = 1
  2. 2
    F = AB + BC + CA
    Three overlapping pairs (6 switches)
  3. 3
    F = AB + C(A + B)
    Factor out C: only 5 switches
Answer: F = AB + C(A + B)

Majority logic, also used to trust 2 of 3 sensors in aircraft.

Q4

The Staircase Light

Question 4

A staircase light has one switch at the bottom (x) and one at the top (y). Flipping either switch must toggle the light. Both start down (0) with the light OFF. Design the circuit.

Click the wall switches on the stairs.

Solution
  1. 1
    F = 1whenx ≠ y
    0 0 → OFF, one flip → ON, two flips → OFF
  2. 2
    F = x'y + xy'
    SOP from rows 01 and 10
  3. 3
    F = x ⊕ y
    Exclusive OR (XOR); already minimal
Answer: F = xy' + x'y = x ⊕ y

In real wiring, x and x′ are one two-way (SPDT) switch.

Q5

The Mirror Map

Question 5

Simplify F(A, B, C, D) = Σm(0, 2, 5, 7, 8, 10, 13, 15) with a Karnaugh map. What surprising pattern appears?

  1. 1
    Plot the 8 ones
    Rows AB and columns CD in Gray-code order
  2. 2
    Centre block→ BD
    B = 1 and D = 1 everywhere inside it
  3. 3
    Four corners→ B'D'
    Edges wrap around, so the corners are neighbours
Answer: F = BD + B'D' = B ⊙ D

XNOR of B and D. Flip A or C with the switches above: F never changes. 32 switches → 4.

Q6

The Bank Locker

Question 6

A locker opens (L = 1) when the Manager’s key M AND the Cashier’s key C are inserted, OR the emergency code E is entered. When does it stay LOCKED? Find and simplify L'.

Solution
  1. 1
    L = MC + E
    Keys in series, code in parallel
  2. 2
    L' = (MC + E)'= (MC)'E'
    De Morgan’s law
  3. 3
    L' = (M' + C')E'
    De Morgan’s law again
  4. 4
    Locked = no code AND a key missing
    Read the result in words
Answer: L' = (M' + C')E'

Series ↔ parallel swap, every switch complemented. This lamp lights when the locker is LOCKED.

Boolean Algebra All Around Us

Processors

Adders inside every CPU are built from XOR and AND gates.

Memory

Flip-flops made of NAND or NOR gates store each bit of RAM.

Traffic Signals

Controllers decide which light turns green using logic rules.

Security Systems

“Key AND code, OR override”: exactly our Q6 locker.

Search Engines

Queries like maths AND (logic OR circuits) NOT biology.

Home Wiring

Programming

Key Takeaways

  1. 1
    Two values, three operations.
    Everything is built from 0, 1 and the operations +, · and ′.
  2. 2
    Laws come in dual pairs.
    Swap + ↔ · and 0 ↔ 1: prove one law, get its dual free.
  3. 3
    De Morgan flips the circuit.
    Break the bar, change the sign; series ↔ parallel.
  4. 4
    Circuits are expressions.
    Series = AND, parallel = OR, lamp = output.
  5. 5
    Simplify to save.
    Laws and K-maps give the same output with far fewer switches.
